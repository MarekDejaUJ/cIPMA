# Rescale Data to 0-100 Range

This helper function rescales vector data based on theoretical minimum
and maximums.

## Usage

``` r
rescale_0_100(x, min_val, max_val)
```

## Arguments

- x:

  Numeric vector.

- min_val:

  Theoretical minimum of the scale.

- max_val:

  Theoretical maximum of the scale.

## Value

A numeric vector rescaled between 0 and 100.
