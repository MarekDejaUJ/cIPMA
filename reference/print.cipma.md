# Print cIPMA Results

Prints the combined table: importance, performance, the CE-FDH effect
size and its permutation p-value, the necessity decision at `pi = 1`,
the required level at the target level and the share of cases below the
required level at the chosen tolerance.

## Usage

``` r
# S3 method for class 'cipma'
print(x, ...)
```

## Arguments

- x:

  A cipma object.

- ...:

  Ignored.

## Value

The object `x`, invisibly.
